# 1st Impressions Home Services: independent homepage concept

Unsolicited Concept by add2go. Not commissioned, approved, endorsed or operated by the company. Not its official website.

## Scope
Responsive English homepage only. Static HTML, CSS and JavaScript, mobile menu, keyboard-accessible service tabs, original company website photography, and a disabled estimate interface. No Sanity connection, backend, analytics, form submission or production migration.

Client folder: `clients/1st-impressions/`. Root forwards to the client folder using a relative path compatible with GitHub Pages project hosting.

## Publishing
GitHub Pages: Settings > Pages > Deploy from a branch > main > /(root). HTTPS should remain enabled. The preview is publicly accessible to anyone with the URL. Meta robots noindex,nofollow,noarchive is present on both entry points. Noindex is a search-engine instruction, not authentication or a guarantee of removal from search indexes. Do not add this concept to a production sitemap.

## Assets and claims
Photos are referenced from the company's existing Wix-hosted website and remain external dependencies. Confirm permission before further distribution or commercial reuse. No stock or AI imagery is presented as company work. Captions are descriptive concepts, not verified project case studies. The 40-year experience claim is explicitly attributed to the current company site. No invented testimonials or performance results.

Green #145934 and slate #2c3e50 were extracted from the live site's CSS. Sage #8aac9a is also present in its palette. The warm neutral background is a design extension. The wordmark is typographic exploration, not a replacement approved logo.

## Future website architecture
Recommended production approach: Astro static pages + Sanity Studio + GitHub version control. Sanity manages articles, authors, categories, projects and site settings. Published content triggers a build webhook; rendered HTML is deployed to CDN hosting. Final hosting can be GitHub Pages for static-only builds or Vercel following requirements and plan validation. Private drafts and preview authentication must be handled separately; never ship a write token to the browser.

Sanity article model: title, slug, excerpt, cover image with alt text, Portable Text body, author reference, category references, publishedAt, SEO title and description. Project model: descriptive title, slug, service references, actual verified location, scope, photo gallery with alt text, approved narrative. Editors draft, review and publish without editing code. No real Sanity project or paid service has been created for this prospect concept.

## Production discovery
Confirm service area, legal business name, photo rights, approved logo, project details, warranty terms, source and currency of all trust claims, article ownership and publishing frequency. Preserve the current form's information fields (name, email, phone, address, service and message). Production requires an approved handler, validation, anti-spam, privacy wording and delivery testing. Inventory Wix URLs, map 301 redirects and preserve relevant SEO metadata before any domain cutover. Consent and analytics requirements depend on the chosen production services.

## Validation
Check desktop/mobile layout, image rendering, anchor links, service switching including arrow keys/Home/End, mobile menu including Escape, visible focus, and that all enquiry fields remain disabled. The Pages deployment must complete before sharing its URL.
